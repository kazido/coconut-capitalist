## 1. Gate features and areas behind travel and levels
- Lock features until the player has TRAVELLED to a new area (and has the level): the reactor, the farmers market, fishing books, Releaf, and so on.
  Needs one table "feature -> (area, level)" (probably `configs/areas.toml`), a shared lock check in the services, and a clear "unlocks at X" note on the
  locked screens. Open: which feature goes with which area?
- Later areas should be hard to reach and need good gear for their skills (a tool-power requirement per area or location, on top of the level).
- Fuels for later areas cost more and may take starred materials (`<id>_s2`/`_s3`, see `docs/plans/starred-materials.md`).

## 2. Economy
- Rebalance ALL crafting recipes (`configs/recipes.toml`): fuels, wedges, radar battery, scarab bomb.
- Buff scarab bombs.
- More uses for starred materials (fuels, ship parts, recipes, later upgrades) so they matter beyond tool upgrades.

## 3. Characters, lore and travel
- Tutorial characters walk the player through each skill. Characters also "run" places like Releaf and the farmers market.
- Dialogue: the character's portrait as a thumbnail with a Continue button, several pages the FIRST time ever, and one short page on every revisit
  (a tutorial is shown once). Needs "seen" state per player per character/feature (the player settings document avoids a migration) and portrait art.
- Lore for every area (this is where it comes from).
- A short travelling animation when the ship sails.

## 4. Streamline the UI
- Condense some of the fishing buttons.
- Review every screen's content and buttons and combine or cut where they overlap (one pass over all screens, then a list of changes for the user to approve).
