# Plans

One short file per piece of NOT-yet-built work (goal, decisions made, ordered steps with files and tests). Put a `Status:` line first.
When the work merges, delete its plan in the same commit (history is in git). Idea lists (`notes-*.md`, `*-tomorrow.md`) shrink the same way:
delete a line when it ships. `docs/STATUS.md` says which plans are live.
